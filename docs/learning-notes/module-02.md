# Module 2 — Learning Notes

## What I built

A CRUD IT Asset Register using Ubuntu, Apache, PHP, PDO and MariaDB.

## Security choices

- dedicated application database user
- least privilege
- password outside web root
- prepared statements
- `htmlspecialchars()` output encoding
