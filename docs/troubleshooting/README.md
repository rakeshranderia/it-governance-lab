# Troubleshooting Notes

Troubleshooting is a first-class learning outcome in this repository.

## Recommended format

1. Symptom
2. Plain-English interpretation
3. First hypothesis
4. Commands/tools used
5. Evidence found
6. Root cause
7. Fix
8. Why the fix worked
9. Security/cost implications
10. What this taught me

## Sanitisation

Use placeholders such as:

```text
<PUBLIC-IP>
<SUBSCRIPTION-ID>
<TENANT-ID>
<USERNAME>
```
