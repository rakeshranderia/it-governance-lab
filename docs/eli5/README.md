# ELI5 Guide Series

Each guide should explain one technical concept in plain English and then add the correct technical terminology.

## Standard format

- What is it?
- Why does it exist?
- How does it work?
- What did I build?
- What broke?
- How did I fix it?
- What would this look like in a real organisation?
- What I thought before vs what I understand now
- Five things I now understand
